# Striver Mode

Striver Mode is a skill designed to prevent AI agents from giving up early and encourage persistent problem solving.

Striver Mode 是一个用于防止 AI 在复杂任务中提前放弃的技能，通过系统化排查和多路径攻坚机制持续推进问题解决。

---

# Features | 功能特点

EN:

• Prevents early "cannot solve" responses  
• Encourages systematic debugging  
• Forces multi-path reasoning  
• Promotes end-to-end verification  

CN:

• 防止 AI 过早放弃任务  
• 鼓励系统化问题排查  
• 强制多路径解决方案思考  
• 强调端到端验证与闭环

# Install in OpenClaw | 在 OpenClaw 安装

1. Open OpenClaw  
2. Navigate to **Skills**  
3. Click **Import Skill**  
4. Paste repository URL  

Example:

```
https://github.com/ucsdzehualiu/striver-mode

```

5. Enable the skill
